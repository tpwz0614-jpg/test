IRR / XIRR 計算ツール

設備投資案件のキャッシュフローから IRR・XIRR・NPV・回収期間・MIRR を算出します（Excel の IRR() / XIRR() と数値一致・全てブラウザ内で計算、データは送信されません）。

1. 入力方法

期間の種類
期日付金額
初回の行がプロジェクト開始時点（t=0）の投資額（通常はマイナス）です。

列: amount のみ → IRR / date,amount → XIRR（ヘッダー行は任意）。
例: -1000000,300000,300000,300000,300000,300000

2. 割引率・MIRR パラメータ（任意）

Excel の Excel アップロードや CLI・Python ライブラリとしての利用は リポジトリの irr_xirr_tool をご覧ください（このページと同一のロジックを共有しています）。
